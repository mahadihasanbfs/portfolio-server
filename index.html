API Reference

REST API for the Bright Future Soft website, dashboard, mail and accounts. JSON in, JSON out. Click any endpoint to see inputs and a ready-to-run curl.

Base URL

All routes live under /api/v1 (images also /api/v2).

Format

Send Content-Type: application/json. Image upload is multipart/form-data. Gmail send accepts up to 30 MB (base64 attachments). Most "by id" endpoints take the Mongo _id as a query parameter.

CORS

Allowed origins: brightfuturesoft.com, www.brightfuturesoft.com, localhost:5173.

Known issues

Found while documenting. Worth fixing.

  1. The author key is a static shared secret; anyone with the frontend bundle has it.
  2. JWT_SECRET is hardcoded as 'your_jwt_secret_key' in Middleware/admin_only.js. Move it to .env.
  3. POST /image/upload-image has no auth.
  4. Task get-by-id and get-by-assignedTo read path params the routes never define.
  5. Project update/delete are mounted at /update-blog and /delete-blog.
  6. Run on Node 24 or lower: a dependency crashes on Node 25+ (SlowBuffer removed).
